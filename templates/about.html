About MeraGhar

A machine-learning project for exploring house-price estimation.

MeraGhar is an academic web application that accepts property details and estimates a price using a regression model trained on a supplied dataset. It combines data preprocessing, model evaluation and a simple web interface in one project.

01

Project objective

Build an interactive tool that demonstrates how property attributes such as location, living area, bedrooms, age and amenities can be used as inputs for a price-prediction model.

02

Dataset

The project CSV contains city, locality, bedrooms, bathrooms, living area, floors, construction year, parking, facing, lift, furnishing, garden and price.

The training script checks required columns, converts numeric fields, removes rows with unusable target prices, and handles missing feature values through preprocessing.

03

Machine-learning workflow

The dataset is split into training and testing portions. Numeric fields are imputed and scaled, while categorical fields are imputed and one-hot encoded.

Multiple regression algorithms are trained and evaluated using R², Mean Absolute Error and Root Mean Squared Error.

04

Technology stack

The main technologies used in this implementation are:

Python Flask Pandas Scikit-learn HTML CSS JavaScript Chart.js

Algorithms evaluated

The training script compares Linear Regression, Decision Tree, Random Forest, Extra Trees and Gradient Boosting. The model with the strongest test-set R² score is saved for prediction, using MAE to break ties.

These evaluation results are specific to the supplied dataset and test split; they do not guarantee performance on unseen real-world properties.

Project limitation

Dataset authenticity matters. If the CSV contains synthetic or generated records, the application demonstrates the machine-learning workflow but cannot establish reliable real-market property valuations. Real listing data and independent validation would be required for that purpose.
