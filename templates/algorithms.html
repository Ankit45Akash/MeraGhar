Understanding the metrics

R² score

Indicates how well the model explains variation in the target values. A value closer to 1 usually indicates a better fit on the evaluated data.

Mean Absolute Error (MAE)

The average absolute difference between predicted and actual prices. A lower MAE means smaller average errors on the test set.

Root Mean Squared Error (RMSE)

Measures prediction error while giving greater weight to larger errors. Lower values are generally preferred.

Interpret results carefully. The model is selected using the test-set R² score, with MAE used to break ties. If the dataset contains synthetic records, these scores measure performance on those records and do not prove accuracy on real property listings.
